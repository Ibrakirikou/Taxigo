# 🚕 TaxiGo

> Application Android de gestion pour chauffeurs de taxi.

## 📱 Présentation

TaxiGo est une application Android permettant aux chauffeurs de taxi de gérer facilement leur activité quotidienne : courses, revenus, statistiques et rapports.

L'objectif est de proposer une application simple, rapide et entièrement adaptée à une utilisation mobile.

## ✨ Fonctionnalités

- 🚕 Gestion des courses
- 💰 Suivi des revenus
- 📊 Statistiques d'activité
- 📅 Historique des journées
- 🧾 Génération de rapports PDF
- 💾 Sauvegarde et restauration des données
- 📤 Partage des rapports
- 📍 Recherche d'adresses
- ⚙️ Paramètres
- 🌙 Interface moderne
